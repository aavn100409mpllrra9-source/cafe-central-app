# Aplicación Web Café Central 
Sistema web que nos permite a los clientes consultar el menú de la cafetería, revisar los pedidos desde dispositivos móviles o computadoras
## Problema que resuelve
Facilita la atención a clientas, reduce filas y permite organizar los pedidos de forma más eficiente
## Funcionalidades principales 
* Registro e inicio de sesión de clientes
* Catálogo de productos con sus precios
* Selección e historial de pedidos

  # Tecnologías utilizadas
  * HTML, CSS3, JavaScript
  * Python, Flask
  * Git, GitHub
